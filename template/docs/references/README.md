# References

External material kept in the repository, and **what each one informs**.

**The job:** make a source citable and available, so that a decision resting on
it can be checked by somebody who was not there. That is why the second column
exists — a paper committed with no statement of what it was read for is a paper
nobody will read.

**Not the job:** our own reasoning. What we concluded from a source is an
[ADR](../adr/README.md) or a [design note](../design-notes.md); this directory
holds the source and nothing else.

## What earns a place

- A source a decision **cites**, where the decision would be hard to evaluate
  without it — an algorithm, a specification, a standard.
- Material that is hard to find again, or that changes at its origin. A URL is
  enough for something stable and public; a copy is warranted when the thing
  might move, disappear, or be revised without notice.
- **Captured real input data** belongs with the tests rather than here — it is
  fixture material, and the tests are where somebody looks for it.

A link in the document that cites it is usually sufficient. This directory is for
when it is not.
